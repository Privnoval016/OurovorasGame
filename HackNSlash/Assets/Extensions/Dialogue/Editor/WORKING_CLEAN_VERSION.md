## How to Use It NOW

### 1. Open the Editor
```
Tools → Dialogue System → Open Graph Editor
```

### 2. Create a Graph
```
Click "New" button → Save location
```

### 3. Add Your First Node
```
Click "+ Line" button
→ Blue node appears on canvas ✅
```

### 4. SELECT THE NODE
```
Click on the node
→ It turns GREEN ✅
→ Properties show on right ✅
```

### 5. Edit Properties
```
In properties panel on right:
- Edit "Text Key" field
- Edit "Speaker" field
- Edit "Style" field
- Changes save automatically ✅
```

### 6. Add More Nodes
```
Click "+ Choice" to add choice node
```

### 7. Connect Them
```
Click → button on a node
Click target node to connect
```

### 8. Save
```
Click "Save" button
```
